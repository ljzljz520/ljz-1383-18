# 旅行影集 · 叙事编辑器

站主在 Web 中组织目的、路线与照片；后台 API 持久化章节、图、同行人许可与分享版本。
照片 / 地图节点 / 故事段落通过**稳定引用**连接，拖动章节不会错配图注；跨设备离线编辑
对结构冲突提供可理解的合并；分享按**字段白名单快照**控制姓名、联系方式、精确位置的
独立可见范围；同行人撤回许可会**级联重生成**受影响的图像、文字与索引。

## 运行

```bash
npm install          # express + sql.js (WASM SQLite, 免编译)
node server/index.js # http://localhost:3000  (编辑器 /，访客分享 /share/:token)
node test/acceptance.js   # 48 项验收测试
```

## 架构

| 模块 | 职责 |
|---|---|
| `server/db.js` | sql.js 持久层：内存库 + 写事务原子落盘；`tx` 支持 SAVEPOINT 嵌套 |
| `server/merge.js` | 离线 op 三向合并；所有结构变更（含网页直改）统一走 op 日志 |
| `server/snapshot.js` | 白名单快照 + 发布代次；撤下节点与索引重建 |
| `server/consent.js` | 撤回许可的级联重生成（文字/图像/索引/快照） |
| `server/media.js` | 媒体异步处理 + 崩溃恢复（running→pending 重排队） |
| `public/` | 单页编辑器：拖拽排序、稳定引用插入、离线队列、冲突提示、墓碑清理 |

## 需求 → 实现映射

**稳定引用，拖动不错配.** 正文/图注以 `[[media:ID]]`、`[[node:ID]]`、`[[companion:ID]]`
嵌入，ID 永不变；`refs` 表记录实体关联。拖动章节只更新 `order_key`（fractional
indexing），引用随内容走。渲染按 ID 解析，故图注与照片永不因重排错配。

**离线编辑与可理解合并.** 客户端离线累积带 `base_version` 与 `lamport` 的 op。重连后
`/api/albums/:id/sync` 做三向合并：字段级 LWW、删除优先、重排按 lamport 定胜负；每条
冲突生成人话说明（如“两个标签页同时重排了该章节，已采用较新的位置”），并落 `ops` 日志。

**全章共享 vs 白名单快照.** `POST /share` 支持 `policy=full` 或 `whitelist`。
`visibilityFor` 对每个同行人计算 `name/contact/exact_location` 的最终可见性 =
（许可 granted）∧（白名单允许）。精确位置不可见时节点降级为城市级 `coarse`；
联系方式不可见即省略字段。快照为不可变 JSON，是一致的最小披露单元。

**撤回许可的级联重生成.** `revokeConsent` 在一个事务里：① 改许可状态；② 重写受影响
章节正文与图注中的明文；③ 为同框照片生成脱敏变体（`variant_of`）并登记 `image_variant`
派生物；④ 重建 `search_index`/`sitemap`；⑤ 为每个分享链接生成**新代次**快照，旧代次
`superseded`。绝非只改当前页。

**重连清理与不可撤回范围.** 同步响应携带 `tombstones`（已删章节/节点/媒体、已撤许可），
客户端据此清理本地离线缓存。创建分享时如实登记 `external_copies`（链接可能被缓存/
下载/转发），撤回报告中以 `non_revocable_external` 如实列出这些**无法接触、不可撤回**的副本。

**发布代次一致性.** 访客的路线与章节始终来自同一 `generation` 的不可变快照。撤下节点
推进代次并重建索引，旧代次链接（`/share/:token/gen/:g`）返回 410，避免缓存的旧链接
暴露；被撤节点不会留下暴露私人信息的悬空摘要。

## 验收场景（test/acceptance.js，48 项全过）

1. 拖动章节后图注与照片引用稳定（正文/refs/照片三者一致）
2. 离线稿重新上传已撤信息 → 服务端脱敏 + `purged` 清单 + 墓碑清理
3. 两个标签页同时重排 → lamport 定胜负 + 可理解冲突说明
4. 媒体处理中断 → running 残留被 recover 重排队，最终 ready（不会错配为就绪）
5. 撤回许可 → 文字/图注/图像变体/索引/快照全部级联重生成
6. 旧代次链接被缓存 → 410；当前分享页无已撤信息
7. 不可接触的外部副本如实列为不可撤回范围
8. 撤下节点 → 搜索索引/站点地图/分享页均无悬空摘要
9. 白名单快照：姓名/联系方式/精确位置独立可见范围
10. 全章共享 vs 白名单对比
11. 访客路线与章节来自同一发布代次
